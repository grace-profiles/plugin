NOTE: Currently, Grace framework does not provide a direct `upgrade` command, but it may offer this in the future.

The simplest way is to create two different versions of a new plugin, and then compare the differences between the two versions using the `git-diff` command.

[source,console,subs="attributes"]
----
$ sdk use grace {version}
$ grace -v
$ grace create-plugin com.example.myplugin --profile=plugin --grace-version={version}
$ cd myplugin
$ git init && git add . && git commit -m "Generated by Grace {version}"
$ cd ..
$ grace create-plugin com.example.myplugin --profile=plugin --force
$ cd myplugin
$ git diff
----
